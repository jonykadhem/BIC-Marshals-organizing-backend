# BIC-Marshals-organizing-backend

The backend API for the BIC Marshals Management System. It handles users, events, registrations, marshal positions, assignments, and admin roles, including:

- user authentication and authorization
- creating and managing events
- registering marshals for events
- cancelling registrations
- assigning marshal posts
- managing user roles
- managing event registrations

## Getting Started
### Try The App
visit [Monthly Outing](https://bic-marshals-events-organizing.netlify.app/)

### How To Use
1. Install the required packages.
2. Set up the environment variables.
3. Start the server.
4. Connect the frontend to the backend API.
